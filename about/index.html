GALACTIC BACKWATER

STORIES CHARACTERS UNIVERSE ABOUT

ABOUT

Galactic Backwater is a personal drawing and storytelling project inspired by science, mathematics, history, engineering, and whatever else happens to send my imagination somewhere strange.

There is no particular schedule and probably very little order.

Stories and artwork are drawn and inked by hand using TVPaint.

This project exists mostly because I like drawing and I needed somewhere for these ideas to go.
